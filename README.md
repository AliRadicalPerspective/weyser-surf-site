# Weyser Surf Coach: website redesign

Redesigned homepage and three guide pages for [weysersurf.com](https://weysersurf.com), a surf coach in Santa Teresa, Costa Rica.

**Live preview:** https://aliradicalperspective.github.io/weyser-surf-site/

The preview is set to noindex, so search engines won't list it next to the real site.

## What's here

| Folder | What it is |
|---|---|
| `handoff/` | The developer handoff. Start with `handoff/README.md` for deploy steps, then read `CHANGES.md` and `TO-CONFIRM.md`. |
| `handoff/site/` | Files that go on the web server, using the same paths as the live site (`/assets/...`). |
| `docs/` | The click-through preview served by GitHub Pages (relative links, noindex). |

## Pages

- Homepage
- Your first surf lesson in Santa Teresa: what to expect
- Kids and family surf lessons in Santa Teresa
- Beginner surf beaches in Santa Teresa

Bookings go through WhatsApp; the booking form builds the message.
